# Phoenix dependencies

The dependency graph of the 341 package versions that Phoenix ships at commit
`79cb67a7`, coloured by the results of experiment 2a (build determinism) and
2b (rebuild against nuget.org).

Open it at <https://leosakharoff.github.io/phoenix-dependencies/>.

`index.html` is built by `2-dependencies/graph/scripts/page.py` in the
experiments repository; this repository only hosts it. It is one file and
loads nothing from the network, so it also works when saved and opened
locally.
